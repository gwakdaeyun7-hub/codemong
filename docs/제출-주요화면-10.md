## 화면 선정 기준

"이해도 기반 성장" 이라는 서비스의 핵심 주장이 화면 흐름으로 읽히도록
**학습 → 연습 → 평가(AI) → 성장 확인 → 소통** 순서로 골랐다.
로그인·강좌 소개·게시글 목록·설정처럼 다른 서비스와 차이가 없는 화면은 제외했다.

## 화면별 설명 (PDF 문안)

### 1. 홈

코드몽에 들어오면 처음 보이는 화면입니다. 학습할 수 있는 코스가 카드로 나오고, 로그인하면 카드에 내 진행 상황(완료한 강의 수, 이수율)이 표시됩니다. 상단 메뉴로 코드학습, 실력향상, 커뮤니티, 마이페이지에 들어갈 수 있습니다.

### 2. 강의 목록

Python 코스의 강의 13개(영상 12강 + 프로젝트 1강)를 순서대로 보여줍니다. 강의마다 예상 시간과 진행 상태, 연습 문제 통과 현황이 표시되고, 오른쪽에서 전체 진행률과 뱃지를 볼 수 있습니다. 영상을 보고 그 강의의 연습 문제까지 통과해야 강의가 완료로 처리됩니다.

### 3. 강의 상세 (영상)

강의 영상을 보는 화면입니다. 직접 제작한 3분 내외의 영상이고 자막을 켜고 끌 수 있습니다. 영상을 90% 이상 보면 '학습 완료하기' 버튼으로 학습을 마칠 수 있고, 아래에서 바로 연습 문제로 이동하거나 댓글을 남길 수 있습니다.

### 4. 연습 문제

강의에서 배운 문법으로 짧은 코드를 직접 써 보는 화면입니다. 코드를 작성하고 '제출하고 채점'을 누르면 브라우저 안에서 바로 채점되어 케이스별 결과가 나옵니다. 통과한 문제는 체크 표시가 남고, 강의 완료 판정에 반영됩니다.

### 5. 프로젝트형 강의 (계산기 만들기)

영상 없이 문제를 읽고 프로그램 하나를 완성하는 프로젝트형 강의입니다. 1~6강에서 배운 문법만으로 사칙연산 계산기를 만들고, 실행해 보거나 제출하면 여러 테스트 케이스로 자동 채점됩니다. 막히면 힌트를 단계별로 열어볼 수 있습니다.

### 6. 실력향상

단원별로 전체 코드를 작성해 푸는 문제 은행의 첫 화면입니다. 위쪽 레이더 차트는 내 코드 실력을 5개 축(구문 정확도, 로직 구현도, 개념 이해도, 코드 효율성, 문제 해석력)으로 보여주고 전체 평균과 비교합니다. 아래 단원 카드에서 문제 수와 난이도, 해결한 문제 수를 보고 문제 목록으로 들어갑니다.

### 7. 문제 풀이와 AI 진단

문제를 푸는 화면입니다. 왼쪽에 지문과 예시, 오른쪽에 코드 에디터와 실행 결과가 있습니다. '코드 실행'은 공개 테스트로만 확인하고, '제출 후 채점하기'를 누르면 숨겨진 테스트까지 채점한 뒤 AI가 코드를 읽고 개념 이해도, 코드 효율성, 문제 해석력 점수와 감점 이유를 알려줍니다. 정답을 알려주는 대신 스스로 고칠 수 있도록 힌트로 설명하고, 아래 '내 제출'에서 이전 제출과 AI 진단을 다시 볼 수 있습니다.

### 8. 마이페이지

내 학습 상태를 모아 보는 화면입니다. 완료한 강의, 해결한 문제, 연속 학습일, 연습 통과 수를 보여주고, 성장 리포트에서 5개 축 점수를 전체 평균과 비교할 수 있습니다. 최근 학습한 강의로 바로 이어갈 수 있습니다.

### 9. 학습 캘린더

학습 기록을 달력으로 보여줍니다. 날짜 칸의 색은 그날 공부한 문법 영역, 진하기는 학습 깊이(영상만 봤는지, 문제까지 통과했는지)를 나타냅니다. 날짜를 누르면 그날의 학습 내용이 나오고, 시험 날짜를 등록하면 D-Day와 함께 보강할 단원을 추천해 줍니다.

### 10. 커뮤니티

학습자들이 질문하고 답하는 커뮤니티 게시글 화면입니다. Q&A 글은 답을 얻으면 '해결됨'으로 표시할 수 있고, 좋아요와 댓글, 답글을 남길 수 있습니다. 내 글에 댓글이나 좋아요가 달리면 상단 알림에서 확인할 수 있습니다.
